#### Хранилище конфиденциальных данных GophKeeper

### Назначение

Хранилище конфиденциальных данных GophKeeper включает в себя:
    - Сервер хранилища:
        * Регистрация пользователей;
        * Аутентикация пользователей;
        * Хранение информации о пользователях в БД PosgreSQL (id, login, password_hash);
        // * Хранение данных типа "данные авторизации" - название сайта/приложения, логин и пароль - в БД, в зашифрованном виде;
        // * Хранение данных типа "данные банковской карты" - пользовательское название карты, номер карты, месяц, год, CVV/CVC код, первая строка адреса, вторая строка адреса, регион, город, страна, индекс/ZIP-код/Postal-код - в БД, в зашифрованном виде;
        * Хранение бинарных данных - на диске в {ID} папке, в подпапке /bin/, в зашифрованном виде;
        * Хранение произвольных данных - на диске в {ID} папке, в подпапке /bin/, в зашифрованном виде.

    - CLI-клиент хранилища:
        * Регистрация и авторизация пользователя через API сервера;
        * Шифрование данных;
